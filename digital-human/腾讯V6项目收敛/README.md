## 5. 一页纸现状

- **最强(腾讯②③层)**:AI 对话中枢(内圈 ReAct/上下文/工具治理/grounding/控制安全)+ 子 Agent 能力层骨架(agent_runtime 多域)+ RAG + **评测方法(engine 套实测绿)**。
- **对外口径**:以腾讯 V6 为主线、不求 1:1、按完整项目讲、在建即正常。
- **对腾讯还差(摘要,详见 `00 §3` / 差距分析)**:C 端(小程序+TDesign+硬件)、B 端(CMS+商户)、数字基座(腾讯云产品族+数据底座)、数字人形象+语音落地、多语言/无障碍、非功能(等保/并发/混合部署);子 Agent = 有骨架、缺商业/接驳/活动/便民设施/紧急链路 + 真后端。
- **测评定论(防回头)**:假模型立基线(测引擎,分支覆盖非全样本)→ 出题(RAG=RAGAS / Agent=强模型+假模型逐样本认证)→ 诊断栈评测(DeepEval/agentevals/RAGAS,判官本地)→ OTel+Langfuse 监控 + badcase 回流。认证=执行+断言(断言是认证的判分步,非替代)。
