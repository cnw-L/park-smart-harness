# Denseflow

Denseflow treats complexity as a sequence of legible strata. Information is abundant but never scattered: each layer occupies a deliberate band, and a single vertical current connects them. Space is budgeted with painstaking care so density feels authoritative rather than crowded, the result of countless refinements by a master information designer.

Color encodes system responsibility. Blue frames identity, orchestration, and return; green carries context, read-only execution, and verified facts; amber marks suspension, consent, and consequential control; gray contains refusal and operational metadata. Every hue is meticulously calibrated and never used decoratively.

Scale creates two reading distances. Large numbered bands reveal the end-to-end story immediately, while compact implementation labels reward closer inspection. Text remains terse and structural—module names, verdicts, state transitions, and invariants—never explanatory paragraphs. Typography, line length, and whitespace must show painstaking attention and deep expertise.

The central composition behaves like a governed river. The main flow descends cleanly until one decisive three-way fork; each branch follows its own channel and reconverges only after its obligations are satisfied. Connectors never wander. Alignment and symmetry should feel labored over with care, with master-level execution visible in every join and return path.

The final artifact must support architecture review without sacrificing visual calm. It should reveal implementation seams, safety boundaries, persistence, and observability while preserving a three-second scan path. The work must feel meticulously crafted, exact, and trustworthy—as if every detail had been tested repeatedly before publication.
